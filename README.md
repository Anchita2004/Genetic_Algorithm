# Genetic_Algorithm

This project demonstrates how to solve the classic 0/1 Knapsack Problem using a Genetic Algorithm in Python.  
It includes:

- A set of example items with weights and values
- A genetic algorithm to find a high-value selection under a weight limit
- Clean and modular code, ready to run in Google Colab

---

## Features:
- Customizable item list
- Adjustable genetic parameters (population size, mutation rate, generations)
- Lightweight and beginner-friendly
- Includes a simple timer to measure performance

---

## Files:
- `knapsack.py`: Problem setup and fitness function
- `genetic.py`: Genetic algorithm logic
- `timer.py`: Utility to measure execution time
- `main.ipynb`: Notebook to run everything in Google Colab

---

## How to Use:
1. Open the `main.ipynb` notebook in Google Colab
2. Run all cells in the notebook
3. The algorithm will print the best selection of items found within the weight limit

---

Feel free to modify the parameters and try with different item lists to explore the algorithm's performance!
